# F. 상자 밀어 넣기 ★★

> 공이 상자를 밀어 골 칸 안에 넣는다. 공이 아니라 **상자가** 목표에 가야 한다.

| | |
|---|---|
| 예상 학습 시간 | 40~90분 (영역 9개) — 예상치 |
| 새로 배우는 개념 | **진전 보상과 상한** (RobotArms 4장) · 두 단계 과제(상자로 가기 → 상자 밀기)를 보상 하나로 |
| 출발점 | RollerBall |

---

## 1. 목표 (성공 기준)

- 20판 중 **14판 이상** 상자를 골에 넣는다 (MaxStep 1500 안에).
- **진전 보상 없이**(골인 +1 만) 학습한 것과 비교 — 몇 스텝 만에 처음 성공하는지.

## 2. RollerBall 과 비교

| | RollerBall | 상자 밀어 넣기 |
|---|---|---|
| 목표에 가는 것 | 나 | **상자** |
| 처음 성공까지 | 우연히도 금방 | 우연히는 거의 안 일어남 → **중간 보상**이 필요 |
| 관측 | 나 · 목표 | 나 · **상자** · 목표 |

## 3. 장면 구성

```
PushArea
├── Floor     Plane 10×10
├── Walls     Cube 4개로 바닥 둘레 높이 0.5 벽 — 상자가 떨어지면 끝나버리는 판을 줄인다
├── Agent     Sphere, Rigidbody mass 1
├── Box       Cube 1.0, Rigidbody mass 1 (가벼울수록 밀기 쉽다)
└── Goal      Cube scale (2,0.01,2) 초록, 콜라이더 제거 — 바닥에 그린 칸
```

- 상자 마찰 · 질량은 **Heuristic 으로 밀어 보고** 정한다. 너무 무거우면 사람도 못 민다.

## 4. 설계

| 관측 (8) | 왜 |
|---|---|
| 상자 − 나 (x, z) | 상자로 가는 방향 |
| 골 − 상자 (x, z) | 상자를 밀 방향 |
| 내 속도 (x, z) | |
| 상자 속도 (x, z) | 밀고 있는지, 굴러가는지 |

행동: 연속 2 (x, z 힘).

| 보상 · 끝 | |
|---|---|
| 상자가 골 칸 안 (상자 중심이 칸 안) | **+1, 판 끝** |
| 상자–골 거리가 줄어든 만큼 | **+(이전 거리 − 지금 거리) × 0.5, 한 스텝 ±0.02 로 자른다** |
| MaxStep 1500 | 판 끝 |

> **진전 보상에 상한(Mathf.Clamp)을 거는 이유** — RobotArms 4장 실측: 상한이 없으면 상자가 튕겨나갈 때 한 스텝 보상이 크게 튀어 학습이 흔들린다(보상 −23 까지 발산).
> **나–상자 거리 진전 보상은 넣지 않는다** (넣으면 상자에 붙어만 있고 밀지 않는 쪽으로 갈 수 있다. 넣어 보고 비교해도 좋은 실험).

무작위: 상자 · 골 · 공 위치. 상자는 **벽에서 1.5 이상** (벽에 붙은 상자는 반대쪽으로 못 민다), 상자–골 2 이상.

## 5. 만드는 순서

1. 장면 + Heuristic 으로 **상자를 골에 5번 넣어 본다.** 벽에 낀 상자는 어떻게 되는지 본다.
2. 골인 판정 + 끝 보상만 넣고 짧게 학습 (기준선). 아마 거의 안 오른다 — 그 그래프를 저장해 둔다.
3. 진전 보상 + 상한을 넣고 다시 학습. 그래프 비교.
4. 오르면 영역 9개.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 상자 옆에서 맴돌기만 한다 | 진전 보상이 없거나 너무 작다 |
| 보상이 크게 출렁인다 · Value Loss 가 크다 | 진전 보상 상한이 없다 |
| 상자를 골 쪽으로 밀다가 넘쳐 지나간다 | 정상 학습 과정. 골 칸을 처음엔 크게(3×3) 해서 시작해도 된다 |
| 어떤 판은 절대 성공 못 한다 | 상자가 벽/구석에 생겼다 → 배치 규칙 |
| 아무것도 안 했는데 성공 | 상자가 골 안에서 생겼다 (거리 규칙) |
