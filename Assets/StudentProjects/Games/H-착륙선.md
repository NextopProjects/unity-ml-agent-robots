# H. 착륙선 ★★

> 추력을 뿜어 떨어지는 속도를 줄이고, 기울기를 잡아 패드 위에 **살짝** 내린다.

| | |
|---|---|
| 예상 학습 시간 | 40~90분 (영역 9개) — 예상치 |
| 새로 배우는 개념 | **벌점 크기 조절** — 벌점이 크면 "아무것도 안 하기"·"안 내려가기"를 배운다 · 자원(연료) |
| 출발점 | 새 씬 (세로 평면 X–Y 에서 움직이는 2D 문제) |

---

## 1. 목표 (성공 기준)

- 20판 중 **15판 이상** 패드 위 · 착지 속력 < 1.0 · 기울기 < 15°.
- 연료 벌점 0 / 작게 / 크게 세 가지를 학습해 **착지 성공률 · 남은 연료** 비교.

## 2. RollerBall 과 비교

| | RollerBall | 착륙선 |
|---|---|---|
| 중력 | 바닥에 붙어 있음 | **계속 아래로 끌어당김** — 가만있으면 추락 |
| 행동 | 힘 방향 | **위로 미는 힘(몸 기준)** + 기울이기 |
| 실패 방법 | 떨어짐 하나 | 세게 부딪힘 · 기울어 닿음 · 패드 밖 · 화면 밖 |
| 벌점 | 없음 | 연료 · 충돌 — **크기가 결과를 바꾼다** |

## 3. 장면 구성

```
LanderArea
├── Ground    Cube scale (20,1,2) (0,-0.5,0)
├── Pad       Cube scale (3,0.2,2) (x 무작위, 0.1, 0) 초록, 태그 "Pad"
└── Lander    Cube scale (1,0.6,1) 시작 높이 8
              Rigidbody mass 1 · Freeze Position Z · Freeze Rotation X, Y (Z 축으로만 기운다)
              + 다리 표시용 자식 큐브 2개 (콜라이더는 몸통에만)
```

## 4. 설계

| 관측 (7) | 왜 |
|---|---|
| 패드 − 나 (x, y) ÷ 10 | 어디로 내려가야 하나 |
| 속도 (x, y) ÷ 5 | **착지 속도가 성공을 가른다** |
| 기울기 sin, cos | (G 주차와 같은 이유) |
| 남은 연료 0~1 | 아껴야 하는지 |

(각속도를 넣을지 말지는 실험해 보고 정한다)

| 행동 (연속 2) | |
|---|---|
| 0 | 주 추력 0 ~ 1 (−1~1 을 (a+1)/2 로) × 15 N — `AddRelativeForce(Vector3.up * …)` 몸 기준 위 |
| 1 | 기울이기 토크 −1 ~ 1 × 0.3 — `AddTorque(0, 0, …)`. 작은 상자는 잘 돈다 → Angular Damping 2 도 함께 |

중력 9.81 · 질량 1 → 버티는 데 9.81 N 필요. 15 N 이면 여유가 있다. **이 비율을 바꾸면 난이도가 크게 바뀐다.**

| 보상 · 끝 | |
|---|---|
| 패드에 닿음 · 속력 < 1 · 기울기 < 15° | **+1, 판 끝** |
| 땅/패드에 세게 · 기울어 닿음 | **−1, 판 끝** |
| 연료 사용 | 스텝마다 −0.001 × 추력 (0~1) |
| 높이 > 15 또는 |x| > 10 | −1, 판 끝 (위로 도망가기 방지) |
| 연료 0 | 추력이 안 나감 (판은 계속) |
| MaxStep 1500 | 판 끝 |

착지 판정은 `OnCollisionEnter(Collision c)` 에서 `c.relativeVelocity.magnitude` 로.

무작위: 시작 x ∈ [−6, 6], 시작 속도 x 조금, 패드 x ∈ [−6, 6].

## 5. 만드는 순서

1. 장면만 → Play: 착륙선이 그냥 떨어져 부서지는지.
2. Heuristic (↑ 추력, ←→ 기울이기) 로 **10번 중 몇 번 내리는지** 잰다. 0번이면 추력·토크·시작 높이 조절.
3. 착지 판정을 Console 에 찍어 본다 (속력 · 기울기). 기준을 사람이 성공한 값 근처로.
4. 연료 벌점 **0** 으로 먼저 학습 → 벌점 추가 비교.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 공중에 둥둥 떠서 시간만 끈다 | 끝나는 조건이 MaxStep 뿐 + 충돌 벌점이 크다 → 내려가 봐야 손해. 벌점을 줄이거나 MaxStep 에 −0.5 |
| 추력을 아예 안 쓰고 추락 | 연료 벌점이 너무 크다 |
| 앞뒤(z)로 돈다 | Freeze Rotation X, Y 빠짐 |
| 착지했는데 실패 처리 | 다리 자식 콜라이더가 먼저 닿았다 / relativeVelocity 기준이 너무 빡빡 |
