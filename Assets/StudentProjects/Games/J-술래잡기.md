# J. 술래잡기 ★★★

> 도망자와 술래. 처음엔 술래를 단순한 코드로 두고 도망자만 학습한 뒤, 둘 다 학습시킨다.

| | |
|---|---|
| 예상 학습 시간 | 1단계 30~60분 · 2단계 1~3시간 — 예상치 |
| 새로 배우는 개념 | **Behavior 두 개를 동시에 학습** · 상대가 변하면 내 성적도 변한다 · (선택) **셀프 플레이** 설정 |
| 출발점 | A 동전 모으기 또는 RollerBall |

---

## 1. 목표 (성공 기준)

- **1단계:** "곧장 쫓아오는" 코드 술래를 상대로 도망자가 **평균 15초 이상** 버틴다 (술래가 도망자보다 조금 빠르게).
- **2단계:** 둘 다 학습. 학습된 술래 vs 1단계 도망자, 학습된 도망자 vs 코드 술래 — **엇갈려 붙여** 표로 적는다.

## 2. RollerBall 과 비교

| | RollerBall | 술래잡기 |
|---|---|---|
| 목표 | 가만히 있음 | **나를 이기려고 움직인다** |
| 에이전트 | 1 | 2 (Behavior Name 도 2개) |
| 보상 그래프 | 오르면 잘하는 것 | **상대가 늘면 내 그래프가 내려갈 수 있다** — 그래프만 보고 판단하면 안 된다 |

## 3. 장면 구성

```
TagArea
├── Floor     Plane 10×10 + 벽 4개 (높이 1) — 떨어지기로 판을 끝내지 않게
├── Runner    Sphere 파랑, Rigidbody, RunnerAgent   (Behavior Name "Runner")
└── Chaser    Sphere 빨강, Rigidbody, ChaserAgent   (Behavior Name "Chaser")
              1단계: ChaserAgent 대신 단순 스크립트 (곧장 쫓기)
```

- 술래 속도(힘 배율)를 도망자의 **1.2배** 정도로. 같으면 술래가 영원히 못 잡는다 — 과제가 성립하지 않는다.
- 한 판의 끝(잡힘)은 **두 에이전트 모두** 끝낸다. 한쪽만 `EndEpisode` 하면 다른 쪽은 판이 이어진다.
  둘을 같이 끝내는 가장 쉬운 방법: 영역 스크립트(또는 한쪽 에이전트)가 두 에이전트의 `EndEpisode()` 를 같이 부른다.

## 4. 설계 (도망자)

| 관측 (6) | 왜 |
|---|---|
| 술래 − 나 (x, z) ÷ 10 | 도망칠 방향 |
| 내 속도 · 술래 속도 (x, z) | 술래가 어디로 오고 있나 |

(벽까지 거리는? 넣지 않으면 구석에 몰린다 → 넣을지 실험)

| 보상 · 끝 (도망자) | |
|---|---|
| 살아 있는 동안 | 스텝마다 **+0.001** |
| 잡힘 (거리 < 1) | **−1, 판 끝** |
| MaxStep 1500 (약 30초) | 판 끝 — 끝까지 버티면 성공 |

술래 보상은 정확히 **반대** (잡으면 +1, 스텝마다 −0.001).

## 5. 만드는 순서

1. 장면 + 도망자 Heuristic (WASD) + **코드 술래**. 사람이 도망쳐 본다 → 술래 속도 결정.
2. 도망자만 학습 (`behaviors: Runner:`). 버티는 시간 기록.
3. 술래도 Agent 로 바꾸고 yaml 에 `Chaser:` 추가 → 둘 다 학습. 두 Behavior 가 한 번에 학습된다.
4. 결과 모델 4개(코드/학습 × 도망자/술래)로 엇갈려 붙이기.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 한쪽만 새 판, 다른 쪽은 이어짐 | `EndEpisode` 를 한쪽만 불렀다 |
| 도망자가 구석에서 안 나온다 | 벽 정보가 관측에 없다 |
| 2단계에서 둘 다 그래프가 오르락내리락 | 정상. 상대가 변하기 때문. **고정된 상대와 붙여서** 평가한다 |
| 파이썬이 안 붙는다 | yaml 의 behaviors 키 두 개와 Behavior Name 철자 |

## 7. 다음 단계 (선택)

- **셀프 플레이 설정** — yaml 각 behavior 에 `self_play:` 를 넣고 Behavior Parameters 의 **Team Id** 를 다르게(0 / 1).
  과거 상대 모델(유령)과도 붙어 보며 학습해 한쪽이 상대 하나에만 맞춰지는 것을 줄인다.
  ML-Agents 문서 *Training Configuration File → Self-Play* 를 읽고, 넣기 전/후 엇갈림 표 비교.
- **장애물 몇 개** — 숨을 곳이 생기면 무엇을 배우는지.
