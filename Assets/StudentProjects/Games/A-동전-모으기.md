# A. 동전 모으기 ★

> 공이 바닥 위의 동전을 **계속** 먹는다. 먹으면 동전이 다른 자리에 다시 생긴다.

| | |
|---|---|
| 예상 학습 시간 | 10~20분 (영역 9개) — 예상치, 실제로 재서 적는다 |
| 새로 배우는 개념 | **판을 끝내지 않는 반복 과제** · 에피소드 길이 대신 "한 판에 먹은 개수"로 성적 보기 |
| 출발점 | `Assets/RollerBall` 을 복사해서 시작해도 된다 |

---

## 1. 목표 (성공 기준)

- 학습된 공이 **MaxStep 1000 동안 동전을 평균 8개 이상** 먹는다 (20판 평균).
- 사람이 키보드로 같은 시간 동안 먹는 개수와 비교해 적는다.

## 2. RollerBall 과 비교

| | RollerBall | 동전 모으기 |
|---|---|---|
| 목표에 닿으면 | +1, **판 끝** | +1, **동전만 옮기고 판은 계속** |
| 판이 끝나는 때 | 성공 · 떨어짐 | 떨어짐 · MaxStep |
| MaxStep | 0 (없음) | **1000 꼭 필요** (없으면 판이 영원히 안 끝난다) |
| 잘하는지 보는 법 | 에피소드 길이가 짧아짐 | **누적 보상(= 먹은 개수)이 커짐** · 길이는 늘 1000 |

## 3. 장면 구성

```
CoinArea                (빈 오브젝트, 위치 0,0,0 — 나중에 복제한다)
├── Floor               Plane, scale (1,1,1) = 10×10
├── Agent               Sphere, 위치 (0,0.5,0), Rigidbody (mass 1)
│                       + CoinAgent + Behavior Parameters + Decision Requester
└── Coin                Cylinder, scale (0.5,0.05,0.5), Collider 는 Is Trigger
```

- Coin 은 `Is Trigger` 로 둔다. 공이 동전에 부딪혀 튕기면 안 된다.
- 판정은 트리거 이벤트 대신 **거리 (< 0.8)** 로 해도 된다. 더 단순하다.

## 4. 설계

| 관측 (4) | 왜 |
|---|---|
| 동전 − 나 (x, z) | 어느 쪽으로 가야 하는지. **상대 위치**라 내 절대 위치는 필요 없다 |
| 내 속도 (x, z) | 브레이크를 언제 밟을지 |

| 행동 (연속 2) | -1 ~ +1 |
|---|---|
| 0 | x 방향 힘 |
| 1 | z 방향 힘 |

| 보상 · 끝 | |
|---|---|
| 동전에 닿음 | **+1** → 동전을 새 자리로 (판은 계속) |
| 바닥에서 떨어짐 (y < 0) | 판 끝 (보상 없음) |
| MaxStep 1000 | 판 끝 |

| 무작위 | |
|---|---|
| 동전 자리 | 바닥 안 x, z ∈ [-4, 4] — **공과 1.5 이상 떨어지게** (생기자마자 먹으면 공짜 점수) |

## 5. 만드는 순서

1. **장면만** 만든다 (위 Hierarchy). Play 해서 공이 바닥 위에 서 있는지 본다.
2. Agent 스크립트에 `Heuristic` 만 먼저 쓴다 (WASD → 행동 2개). `Behavior Type = Heuristic Only`.
3. `OnActionReceived` 에 힘 주기를 쓴다. **키보드로 굴려 본다.** `forceMultiplier` 를 정한다 (10에서 시작).
4. 동전 판정 + 동전 옮기기를 넣는다. **키보드로 동전 5개 먹어 본다.** 먹는 순간 동전이 사라져 다른 곳에 생기는지.
5. `CollectObservations` (4칸) — Behavior Parameters 의 Space Size 를 4 로.
6. `OnEpisodeBegin`: 떨어졌으면 공을 가운데로 · 속도 0. 동전 새 자리.
7. Max Step 1000. Behavior Type 을 Default 로 → `mlagents-learn` 첫 학습 (max_steps 5만).
8. 보상이 오르면 **영역을 9개 복제**(같은 Behavior Name)해서 다시 학습. 위치는 전부 `localPosition` 인지 확인.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 판이 안 끝난다 | Max Step 0 |
| 복제한 영역에서만 이상하다 | `position` 을 썼다. `localPosition` 으로 |
| 시작하자마자 +1 을 받는다 | 동전이 공 바로 옆에 생겼다 |
| 에피소드 길이 그래프가 평평하다 | 정상이다. 반복 과제는 길이가 늘 MaxStep. **Cumulative Reward** 를 본다 |
| 바닥 끝으로 굴러떨어지기만 한다 | 학습 초반엔 정상. 계속되면 동전이 바닥 끝 근처에 너무 자주 생기지 않나 본다 |

## 7. 다음 단계 (하나만 고른다)

- **동전 3개 동시에** — 관측은 "가장 가까운 동전"만. 관측 수는 그대로 4.
  → 어느 동전을 고를지까지 배워야 한다. 학습이 느려지는지 숫자로 비교.
- **떨어지면 −1** — 벌점 하나로 행동이 얼마나 조심스러워지는지 비교.
