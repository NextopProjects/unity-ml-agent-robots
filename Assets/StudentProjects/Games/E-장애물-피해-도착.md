# E. 장애물 피해 도착 ★★

> 무작위로 놓인 기둥 사이를 지나 목표에 닿는다. 기둥은 **눈(광선 센서)** 으로 본다.

| | |
|---|---|
| 예상 학습 시간 | 30~60분 (영역 9개) — 예상치 |
| 새로 배우는 개념 | **센서 컴포넌트 (Ray Perception Sensor 3D)** — 관측을 코드로 적지 않고 붙이기만 한다 · 태그로 구분하기 |
| 출발점 | B(멈춰서 도착) 또는 RollerBall |

---

## 1. 목표 (성공 기준)

- 기둥 4개 무작위에서 20판 중 **15판 이상** 부딪히지 않고 도착.
- **센서를 끈 모델**(관측에서 광선 제거)과 충돌률 비교.

## 2. RollerBall 과 비교

| | RollerBall | 장애물 피해 도착 |
|---|---|---|
| 관측 | 코드 8칸 | 코드 4칸 + **광선 센서 (자동)** |
| 실패 | 떨어짐 | 떨어짐 · **기둥에 부딪힘** |
| 판마다 바뀌는 것 | 목표 | 목표 · **기둥 자리** |

## 3. 장면 구성

```
ObstacleArea
├── Floor       Plane 10×10
├── Agent       Sphere, Rigidbody, ObstacleAgent, Behavior Parameters, Decision Requester
│   └── (같은 오브젝트에) Ray Perception Sensor 3D
├── Target      Cube 0.8, 태그 "Goal"
└── Pillars     빈 오브젝트
    ├── Pillar0~3   Cylinder scale (0.6,1,0.6), 태그 "Obstacle"
```

**Ray Perception Sensor 3D 설정 (시작값)**

| 칸 | 값 | 뜻 |
|---|---|---|
| Detectable Tags | `Obstacle`, `Goal` | 광선이 맞은 것이 무엇인지 구분할 이름표 |
| Rays Per Direction | 3 | 가운데 1 + 양옆 3씩 = 7줄 |
| Max Ray Degrees | 90 | 좌우 반각 |
| Ray Length | 8 | |
| Sphere Cast Radius | 0.3 | 가는 틈을 놓치지 않게 |

> **공이 굴러가면 센서도 같이 돈다.** 공(Sphere)에 센서를 붙이면 광선이 빙글빙글 돈다.
> 해결: 센서를 **회전하지 않는 자식**에 달거나, Rigidbody 의 `Freeze Rotation` 을 켜서 공이 미끄러지게 한다. 둘 중 하나를 고르고 이유를 적는다.

## 4. 설계

| 관측 (코드 4 + 센서) | 왜 |
|---|---|
| 목표 − 나 (x, z) | 목표 방향 (기둥에 가려도 알게) |
| 내 속도 (x, z) | |
| 광선 센서 | 기둥이 어디 있는지. **코드에 적지 않는다** — Behavior Parameters 의 Space Size 는 4 |

행동: 연속 2 (x, z 힘).

| 보상 · 끝 | |
|---|---|
| 목표 도착 | **+1, 판 끝** |
| 기둥 충돌 (`OnCollisionEnter`, 태그 Obstacle) | **−0.5, 판 끝** |
| 떨어짐 | 판 끝 |
| MaxStep 1000 | 판 끝 |

무작위: 목표 · 기둥 4개 · 공 시작 위치. **기둥끼리 / 공 · 목표와 1.5 이상** 떨어지게 (막혀서 못 가는 판이 없게).

## 5. 만드는 순서

1. 장면 + 태그 만들기 (Tags & Layers 에서 `Obstacle`, `Goal` 추가).
2. **기둥 없이** RollerBall 처럼 먼저 학습되는지 확인 (기준선).
3. 기둥 4개 + 충돌 판정 + 무작위 배치. Heuristic 으로 피해 가 본다.
4. 센서를 붙이고 Scene 뷰에서 **광선이 기둥에 맞아 색이 바뀌는지** 본다 (Play 중, 에이전트 선택).
5. 학습 → 센서 없는 버전과 비교.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 광선이 아무것도 못 본다 | Detectable Tags 와 오브젝트 태그 철자가 다르다 · 광선 높이(Start/End Vertical Offset)가 바닥에 박혔다 |
| 광선이 빙글빙글 돈다 | 굴러가는 공에 붙였다 (위 상자) |
| 학습 초반 충돌만 반복하다 아예 안 움직인다 | 충돌 벌점이 크다. −0.5 → −0.2 로 비교 |
| 판 시작부터 부딪힘 | 기둥과 공이 겹쳐 생겼다 |
