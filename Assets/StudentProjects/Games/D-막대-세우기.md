# D. 막대 세우기 ★

> 수레를 좌우로 움직여 수레 위 경첩에 달린 막대가 쓰러지지 않게 한다.

| | |
|---|---|
| 예상 학습 시간 | 10~30분 — 예상치 |
| 새로 배우는 개념 | **"버티기" 보상** (도착점이 없다) · MaxStep 이 곧 만점 · 관절(HingeJoint) 각도 읽기 |
| 출발점 | 새 씬 |

---

## 1. 목표 (성공 기준)

- 시작 각도 ±5° 무작위에서 **MaxStep 1000 을 20판 중 18판 버틴다.**
- 사람이 키보드로 몇 초 버티는지 먼저 재서 적는다 (생각보다 짧다).

## 2. RollerBall 과 비교

| | RollerBall | 막대 세우기 |
|---|---|---|
| 보상 | 끝에 한 번 +1 | **살아 있는 동안 매 스텝 +0.01** |
| 판 끝 | 성공 | **실패(넘어짐)** · MaxStep |
| 잘하는지 | 길이가 짧아짐 | **길이가 길어짐** (1000 이면 만점) |
| 관측 | 위치 | 각도 · 각속도 (빠르게 변하는 값) |

## 3. 장면 구성

```
PoleArea
├── Rail      Cube scale (8,0.1,0.3)   — 눈으로 보이는 레일. 콜라이더 제거
├── Cart      Cube (0,0.25,0) scale (0.8,0.3,0.5)
│             Rigidbody mass 1 · Constraints: Freeze Position Y, Z · Freeze Rotation X, Y, Z
└── Pole      Cube (0,1.15,0) scale (0.1,1.5,0.1)  ← Cart 의 자식이 아니다
              Rigidbody mass 0.1 · HingeJoint (Connected Body = Cart, Axis = (0,0,1), Anchor = (0,-0.5,0))
              Constraints: Freeze Position Z · Freeze Rotation X, Y
```

- **막대는 수레의 자식으로 두지 않는다.** 둘 다 Rigidbody 이고 관절로만 연결한다 (RobotArms 의 "Transform 아래 Rigidbody" 함정과 같은 이야기).
- Anchor 는 로컬 좌표라 스케일이 곱해진다. (0,-0.5,0) = 막대 아래 끝.
- 수레와 막대가 서로 부딪히지 않게 HingeJoint 의 `Enable Collision` 은 끈다(기본값).

## 4. 설계

| 관측 (4) | 왜 |
|---|---|
| 수레 x ÷ 4 | 레일 끝을 피하려고 |
| 수레 속도 x | |
| 막대 각도 (라디안) | 얼마나 기울었나 |
| 막대 각속도 z | **어느 쪽으로 넘어지는 중인가** — 각도만으로는 모른다 |

막대 각도: `HingeJoint.angle` (도) 을 써도 되고, `Vector3.SignedAngle(Vector3.up, pole.up, Vector3.forward)` 로 직접 재도 된다.
**eulerAngles 는 쓰지 않는다** (0 ↔ 360 으로 뒤집힌다).

| 행동 (연속 1) | 수레에 x 힘 (× 10) |

| 보상 · 끝 | |
|---|---|
| 매 스텝 살아 있음 | **+0.01** |
| 각도 > 30° 또는 수레가 |x| > 4 | 판 끝 (벌점 없음 — 이미 못 받는 보상이 벌이다) |
| MaxStep 1000 | 판 끝 |

`OnEpisodeBegin`: 수레를 가운데로 · 속도 0, 막대를 ±5° 무작위로 기울이고 속도 · 각속도 0.

## 5. 만드는 순서

1. 장면만 만들고 Play — **막대가 혼자 쓰러지는지** 본다. 안 쓰러지면 관절 축이 틀렸다.
2. Heuristic (A/D) 로 사람이 버텨 본다. 너무 어려우면 **막대를 길게**(긴 막대가 천천히 넘어진다) 하거나 힘을 조절. 바꾼 값은 기록.
3. 넘어짐 판정 + 처음 자세로 되돌리기. **되돌릴 때 속도도 0 으로** — 안 그러면 쓰러지던 힘이 남는다.
4. 관측 4칸 · 보상 → 학습.

## 6. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 막대가 수레와 따로 놀거나 튄다 | 막대를 수레 자식으로 넣었다 |
| 막대가 앞뒤(z)로 넘어진다 | 막대 Constraints 에 Freeze Rotation X, Y 가 없다 |
| 판이 시작하자마자 끝난다 | 되돌릴 때 각속도를 안 지웠다 |
| 레일 끝으로 달려가 끝낸다 | 수레 위치를 관측에 안 넣었다 |
| 시뮬레이션이 덜덜 떨린다 | Decision Period 가 크다 (5 → 1~2 로). 빠른 과제는 자주 결정해야 한다 |
