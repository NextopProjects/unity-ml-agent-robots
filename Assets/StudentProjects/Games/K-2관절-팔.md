# K. 2관절 팔로 버튼 누르기 ★★★

> 책상 위 평면 2관절 팔이 무작위 자리의 버튼에 팔 끝을 가져간다.
> RobotArms 3장(도달 학습)을 **안내 없이 혼자 다시 만드는** 과제다.

| | |
|---|---|
| 예상 학습 시간 | 30~60분 (영역 9개) — 예상치 |
| 새로 배우는 개념 | **도달 범위 검증** (정기구학으로 미리 계산) · Transform 으로 관절 돌리기 · "환경을 먼저 의심" |
| 출발점 | 새 씬. `Assets/RobotArms` 코드는 **보지 않고** 만든 뒤 마지막에 비교한다 |

---

## 1. 목표 (성공 기준)

- 20판 중 **18판 이상** 팔 끝이 버튼에 0.15 안으로 (MaxStep 500 안에).
- **도달 가능 영역을 계산해 문서에 적고**, 버튼이 그 안에서만 생기게 한다.

## 2. RollerBall · RobotArms 3장과 비교

| | RollerBall | 2관절 팔 | RobotArms 3장 |
|---|---|---|---|
| 움직임 | 힘 | 관절 각도 2개 | 관절 각도 3개 (3D) |
| 공간 | 평면 | **평면 (위에서 본 X–Z)** | 3D |
| 갈 수 없는 곳 | 없음 | **있다** (너무 가깝거나 멀면) | 있다 |

## 3. 장면 구성

```
ArmArea
├── Desk       Cube scale (5,0.1,5)
├── Arm
│   └── Base   빈 오브젝트 (scale 1!) — ArmAgent 붙는 곳
│       └── J1          빈 오브젝트 (Y 축 회전) + 원기둥 표시
│           ├── Link1   Cube scale (0.1,0.1,1.0) 위치 (0,0,0.5)
│           └── J2      빈 오브젝트 (0,0,1.0), Y 축 회전
│               ├── Link2  Cube scale (0.1,0.1,0.8) 위치 (0,0,0.4)
│               └── Tip    빈 오브젝트 (0,0,0.8)
└── Button     Cylinder scale (0.3,0.05,0.3), 콜라이더 제거
```

- **관절 · Tip 은 scale 1 빈 오브젝트.** 스케일 있는 큐브 아래에 관절을 달면 팔이 찌그러진다 (RobotArms 함정 그대로).
- 물리 없음 — 각도를 `localRotation = Quaternion.Euler(0, 각도, 0)` 으로 직접 넣는다.

## 4. 도달 범위부터 계산한다 (코드 쓰기 전에)

링크 1.0 + 0.8, 관절 범위 J1 −90~90°, J2 −150~150° 라면:

- 가장 멀리 = 1.0 + 0.8 = **1.8**
- 가장 가까이 = 1.0 − 0.8 = 0.2 ... 하지만 J2 가 ±150° 까지라 **실제로는 더 멀다** → 얼마인가?
- 각도를 1° 씩 전부 돌려 보는 에디터 스크립트(또는 표 계산)로 **실제 닿는 거리 범위**를 잰다. ← 이게 이 과제의 핵심 숙제
- 버튼은 잰 범위의 **안쪽 여유**를 두고 생기게 한다 (예: 잰 범위가 0.4~1.8 이면 0.6~1.6).

## 5. 설계

| 관측 (6) | 왜 |
|---|---|
| 관절 각도 2개 ÷ 최대 | 지금 자세 |
| 버튼 − 팔 끝 (x, z) | 남은 거리 · 방향 |
| 버튼 위치 (x, z) | 자세를 고르는 데 도움 (뺐을 때와 비교) |

| 행동 (연속 2) | 관절 속도 (−1~1 × 90°/초 × Δt), 범위 안으로 자름 |

| 보상 · 끝 | |
|---|---|
| 팔 끝–버튼 < 0.15 | **+1, 판 끝** |
| 거리 진전 | + (이전 − 지금), 한 스텝 ±0.02 상한 |
| MaxStep 500 | 판 끝 |

## 6. 만드는 순서

1. 계층 구조만 → Scene 뷰에서 J1 · J2 Y 회전을 손으로 돌려 본다.
2. **도달 범위 계산** → 문서에 숫자 기록.
3. Heuristic (Q/A, W/S) 로 버튼 10개 눌러 보기.
4. 관측 · 보상 → 학습.
5. 끝나면 `Assets/RobotArms/RobotArmAgent.cs` 와 내 코드를 비교. 다른 점 3가지를 적는다.

## 7. 자주 밟는 함정

| 증상 | 원인 |
|---|---|
| 팔이 납작하게 찌그러진다 | 스케일 있는 오브젝트 아래에 관절 |
| 학습이 안 되는 판이 섞여 있다 | 버튼이 닿을 수 없는 곳에 생긴다. **환경을 먼저 의심** |
| 각도가 갑자기 360 근처로 튄다 | eulerAngles 로 읽었다. 각도를 내 변수로 들고 있는다 |
