자율 프로젝트 — 플레이 가능한 초안

과제마다 게임이 어떻게 흘러가고, 그 위에 강화학습(관측 · 행동 · 보상 · 에피소드)이 어떻게 붙는지 직접 조작하며 확인한다.

보는 법
  1. 사람 (Heuristic) 으로 먼저 플레이한다 — 사람이 못 하면 에이전트도 못 한다.
  2. 무작위 (학습 전) 로 바꿔, 아무것도 모르는 에이전트가 어떻게 움직이고 어떤 보상을 받는지 본다.
  3. 규칙 (학습 후 예시) 은 학습이 잘 됐을 때의 모습을 흉내 낸 손 규칙이다 (신경망 아님). 목표로 삼을 플레이.
  4. 오른쪽 패널에서 결정마다 바뀌는 관측 · 행동, 들어오는 보상, 불리는 ML-Agents 메서드를 따라간다.
  5. 아래쪽의 보상 표와 C# 코드 뼈대가 Unity 에서 붙일 내용이다. 자세한 설계는 각 과제의 기획서 (PDF · md).

이 초안은 브라우저용 단순 물리다. 숫자(힘 · 속도 · 기준)는 기획서의 예시 설계와 같지만, Unity 물리와 똑같이 움직이지는 않는다. 파일을 더블클릭해 브라우저로 연다 (인터넷 필요 없음).
